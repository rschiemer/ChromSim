# 0012 — xlrd for legacy Excel (.xls) UNICORN exports

- Status: accepted (approved by the maintainer, 2026-11-27)
- Date: 2026-11-27

## Context
UNICORN 5 exports chromatograms as Excel 97–2003 workbooks (`.xls`). openpyxl (ADR 0006) reads
only `.xlsx`, so such files had to be converted by hand. Public data sets use the format
(e.g. github.com/ismailuddin/fplc-chromatogram), and labs still hold archives of them.

## Decision
Add `xlrd >= 2` (conda-forge, pure Python, BSD licence) as a core dependency. Version 2 reads
only `.xls`, which is exactly what is needed; `.xlsx` stays with openpyxl. The new importer
`akta_xls` turns the cells into the same text rows as the other UNICORN importers and reuses
their parser.

## Consequences
- `.xls` UNICORN exports import with `read_chromatogram` like any other export.
- Writing `.xls` is not supported and not needed. The test fixture
  `tests/data/akta/cex_mab_hmw_run01.xls` is our synthetic `.xlsx` fixture converted with
  LibreOffice by `tests/data/generate_fixtures.py` (LibreOffice is only needed to regenerate it).
- Updating `pixi.lock` from a network that blocks prefix.dev needs the PyPI-name mapping from
  GitHub (`conda-pypi-map`), set temporarily; the committed manifest is unchanged.
