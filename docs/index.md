# ChromSim

ChromSim is a toolbox for mechanistic modeling of preparative chromatography, built on
[CADET](https://cadet.github.io). You can use it from notebooks or scripts, from the `chromsim`
command line or, optionally, from a local web UI. All three do the same things.
